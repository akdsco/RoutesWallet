## Problem

Accessibility gaps on the route list:
- Route cards are interactive (click = select) but use `role="listitem"` — they
  should be real buttons (`<button>` / `role="button"`) so keyboard + screen
  readers treat them correctly.
- Add keyboard navigation through the list (↑/↓ to move between cards, Enter/Space
  to select), visible focus, and a focused-hint copy line.
- (Related review findings already noted: clear-search/POI-chip touch targets,
  hover panel being mouse-only — fold in if cheap.)

Follow the repo testing convention: select by **role**, assert on semantics/state
(not copy). Verify with a component/DOM test where practical.

## Key files
- `web/src/components/Sidebar.tsx` — `RouteCard` (role, keydown, focus), list container
- `web/src/App.tsx` — selection wiring / focus management
