## Problems

**TB-51 — Strava colour fidelity.** The heat is a per-theme red ramp (prototype):
light = orange→deep-maroon (hot darkest), dark = dim-red→bright-amber (hot
brightest), mirroring how Strava inverts by basemap. It's close but not exact.
Sample Strava's actual gradient stops (light + dark), tune hues/steps, consider a
smooth interpolated gradient vs the 6 discrete tiers. Also finish retiring the old
ink path if any remnants remain and keep the colour tests pointed at `HEAT_RAMP`.

**TB-48 — retune tiers against real data.** The overlap-count thresholds in
`HEAT_RAMP` were set against synthetic data (peaks ~20); real club data peaks
lower (~6–10). Re-derive the tier `max` breakpoints from the actual 125-route
`routes.geojson` so the gradient uses its full range.
