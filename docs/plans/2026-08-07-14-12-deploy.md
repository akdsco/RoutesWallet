# deploy

- Date: 2026-08-07 14:12

## Problem / Context

`main` is now the loose monorepo (PR #2 merged) with `web/` ready to ship. Goal:
get the static web app live on **Cloudflare Pages** — free, 24/7, no backend —
per [`docs/DEPLOYMENT.md`](../DEPLOYMENT.md). Target domain: `routeswallet.app`.

The actual go-live is Cloudflare dashboard config (the user's account, not code).
This branch carries the small code prep that makes a public launch tidy, plus the
runbook so the steps are recorded.

## Plan

**User (Cloudflare dashboard — the critical path):**

1. Workers & Pages → Create → Pages → Connect to Git → `RoutesWallet`.
2. Build config: Root dir `web`, preset Vite, build `npm run build`, output `dist`.
3. Production branch `main`. Deploy → get the `*.pages.dev` URL.
4. Smoke-test the preview (below). Then: custom domain `routeswallet.app`; enable
   Cloudflare Web Analytics (dashboard, no code).

**This branch (code prep, doable now):**

- `web/public/robots.txt` — allow indexing of a public site.
- Social/OG + canonical meta in `web/index.html` so a link shared in WhatsApp/
  Slack unfurls with a title + description. (`og:image` = follow-up ticket; needs
  a real 1200×630 asset.)
- Build already de-risked: a clean `npm ci && npm run build` from a fresh checkout
  succeeds (matches what Cloudflare runs).

## Smoke test (on the first *.pages.dev URL)

- Map + 125 routes load; heat renders.
- Search a place (e.g. "Box Hill") and a postcode (e.g. "EN11") → marker + 25 km
  circle + matches; "Open in Strava" opens.
- Theme toggle flips light/dark. No console errors. Cache headers applied
  (`/assets/*` immutable, `*.geojson` max-age=3600).
