## Problem

Add a **basemap toggle** so users can switch the map style — in particular a
cycling-focused basemap like **CyclOSM** alongside the current CARTO Voyager
(light) / Dark Matter (dark). A small UI control on the map; wire the tile URLs
and swap the tile layer cleanly (the theme effect already replaces the tile
layer, so follow that pattern to avoid the fractional-zoom mis-position bug).

Note: "re-enable dark mode" from the ticket title is **already done** — dark mode
+ the theme toggle ship. The remaining scope is the basemap switcher.
